# VolunTeen

Find volunteer jobs at events organized by student leagues from Timișoara faculties.

Built with React Native, Expo and Firebase.

## Run

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Firebase web app config (optional — without it the app shows sample data).
3. `npx expo start` and scan the QR code with **Expo Go**.

## Firestore

Collections: `leagues` and `jobs` (fields documented in `CLAUDE.md`).
